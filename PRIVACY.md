# Privacy Policy — Play-кнопка для страниц фильмов

Last updated: October 24, 2026

This extension does not collect, store, or transmit any user data.

- It runs only on kinopoisk.ru pages.
- It inserts a button next to the film title. When you click it, the extension builds a new address from the current page URL and opens it in the same tab. This happens entirely in your browser.
- It does not read page content beyond locating the title element.
- It does not use cookies, analytics, tracking, or third-party services.
- It makes no network requests of its own.

Because no data is collected, none is sold, shared, or used for any other purpose.
