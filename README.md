# Кинопоиск → kinokino.vip

Расширение Chrome: на странице фильма или сериала Кинопоиска слева от названия появляется кнопка ▶. Нажатие открывает тот же фильм на kinokino.vip в текущей вкладке.

## Установка
1. Распакуйте архив в постоянную папку (не удаляйте её после установки).
2. Откройте `chrome://extensions` и включите «Режим разработчика» (справа вверху).
3. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
4. Откройте любую страницу фильма на Кинопоиске.

## Сменить домен зеркала
В `src/url.js` поменяйте `MIRROR_ORIGIN`, затем нажмите «Обновить» у расширения в `chrome://extensions`.
